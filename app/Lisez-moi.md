# MyBlocNotes

MyBlocNotes est une application Android développée en **Java** avec **Android Studio**. Elle permet de gérer des notes simplement et éfficace.

## Fonctionnalités

- Créer une note avec un titre et un contenu.
- Afficher les notes dans une liste.
- Modifier une note en appuyant dessus.
- Supprimer une note avec un appui long.
- Annuler et refaire les modifications du texte.
- Conserver les notes dans un fichier `notes.json`.

## Technologies

- Java
- Android Studio
- XML pour les interfaces
- RecyclerView pour afficher les notes
- JSON pour la sauvegarde

## Utilisation

1. Appuyer sur **+** pour créer une note.
2. Écrire le titre et le contenu, puis appuyer sur **Enregistrer**.
3. Appuyer sur une note pour la modifier.
4. Faire un appui long sur une note pour la supprimer.

## Lancer le projet

Ouvrir le projet dans **Android Studio**, attendre la synchronisation Gradle, puis cliquer sur **Run**.
